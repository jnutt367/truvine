Privacy Policy

App: TruVINE
Effective date: October 13, 2026
Operator: Jason Nutt

Overview

TruVINE is a personal channel-management tool used by Jason Nutt for his own TruVINE YouTube channel, @TruVINE365. The app operates only on the Google and YouTube account that Jason authorizes. It is not a public sign-in service and does not offer accounts to other users.

Information the app accesses

Through the YouTube Data API, and only as needed for tasks Jason authorizes, TruVINE may access:

  • Channel information and channel statistics.
  • Video metadata, including titles, descriptions, tags, publishing status, and statistics.
  • Playlist and upload information for Jason’s own channel.
  • Comments and related channel information when Jason uses comment-review or channel-maintenance features.
  • Content and files Jason directs the tool to use for his own channel, such as video files, descriptions, metadata, and thumbnail images.

The app accesses Google user data only after Jason grants authorization through Google’s OAuth consent process.

How information is used

Information accessed through the YouTube Data API is used solely to operate, maintain, and report on Jason Nutt’s own TruVINE channel. Uses include checking channel statistics, preparing and applying authorized metadata or description updates, assisting with authorized uploads and thumbnails, reviewing comments, and maintaining accurate ministry channel reports.

Google user data is not sold. It is not used for advertising, marketing profiles, credit decisions, or any purpose unrelated to operating Jason’s own channel.

Sharing and disclosure

TruVINE does not transfer Google user data to third parties for their own use. Data is processed on the operator’s own private systems for the purposes described in this policy.

Data is sent to Google and YouTube as necessary when the app performs API operations that Jason authorizes — for example, requesting channel statistics or applying an authorized update to his channel. Google’s handling of data submitted to its services is governed by Google’s own policies and terms.

Storage and security

OAuth credentials and access tokens used by TruVINE are stored on the operator’s private systems in permission-restricted files (Unix file mode 0600) and are not published in this repository or on these public information pages.

No security method is perfect, but access to the tool and its stored credentials is limited to the operator’s private systems and authorized channel-management workflow.

Retention

Operational API data is refreshed or overwritten as channel data changes. Locally stored operational information is kept only while it is useful for operating and reporting on Jason’s channel, unless Jason requests its deletion sooner.

Revoking access and requesting deletion

Jason can revoke TruVINE’s access at any time through Google Account security settings for third-party access. Revoking access stops the app from making new API requests with the revoked authorization.

Requests to delete locally stored operational data associated with the app can be sent to jnutt367@gmail.com.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a revised effective date.

Contact

Questions about TruVINE or this privacy policy can be sent to Jason Nutt at jnutt367@gmail.com.
